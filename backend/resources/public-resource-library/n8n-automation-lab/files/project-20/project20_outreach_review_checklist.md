# Project 20 — Outreach Review Checklist

Before a human sends a draft:

- [ ] Recipient is a legitimate business contact and not on DO_NOT_CONTACT.
- [ ] The personalization fact is verified and the source URL is saved.
- [ ] No private/sensitive data was used to personalize the message.
- [ ] Subject line is truthful and not deceptive.
- [ ] Email does not pretend we know the recipient personally.
- [ ] Claims about our offer/proof are accurate.
- [ ] The message has one clear, low-friction CTA.
- [ ] Opt-out wording is present where appropriate / required.
- [ ] Applicable local law and recipient-country rules have been reviewed.
- [ ] Sender domain authentication and deliverability settings are healthy.
- [ ] Human has reviewed the draft before sending.
