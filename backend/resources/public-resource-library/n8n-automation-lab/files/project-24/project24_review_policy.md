# Project 24 — Review Policy

Supported demo modes:

- `none`: do not send a public-review invitation.
- `all_respondents`: send the same neutral public-review invitation to every eligible respondent, regardless of rating or AI sentiment.

Do not implement `positive_only`, `promoters_only`, or logic that blocks unhappy customers while directing only happy customers to a public review page.

Do not offer incentives conditioned on a positive/negative sentiment.
